# MCU_Projects
这是一个单片机学习项目的集合。Wordle、Music Player 和 Music Game Redo 三个项目均基于 STC89C52RC 单片机开发板制作。

## 使用方法
下载对应项目的 Objects 文件夹下的 .hex 文件，直接烧录进单片机即可。

## Wordle
这是一个单片机 Wordle 小游戏，使用矩阵键盘输入，独立按键查看历史记录。

矩阵键盘 1-13 对应输入按键，按下 14 可以切换输入 A-M 和 N-Z 。15 是退格键，16 是确定键。

独立按键 K2 是打开/关闭历史记录，K1 和 K3 是切换历史记录。

每次共计六次猜测机会，猜测结果分为 G (Green) 、Y (Yellow) 、R (Red) 三种，分别对应位置和字母都正确、位置错误字母正确和完全错误三种。

## Music Player
这是音游项目的前置项目，可以选择播放两首音乐：妄想感伤代偿联盟（MKDR）和希区柯克（Hitchcock）。

使用独立按键 K1 和 K3 切换选曲，K2 播放音乐。

播放过程中 K1 和 K3 用于快退/快进 10s ，K2 用于暂停，K4 用于返回选曲界面。

## Music Game Redo
这是一个音游项目的重做版本，原版本因为蜂鸣器和 LCD1602 引脚冲突导致无法正常运行，使用 GPT6 Astra 重做得到该项目。虽然蜂鸣器现在会有些许卡顿导致无法像音乐播放器那样好听，但是至少达成了既定效果。

选曲界面与音乐播放器相同。

游戏开始后屏幕第 12 列会出现一个判定线，音符从左边向右掉落到判定线上，玩家需要在音符恰好落在判定线上时按下对应的独立按键。其中独立按键 K1-K4 对应屏幕从下到上的四个轨道。

按下按钮后会进行判定，如果音符在判定线上称作 Perfect ，获得这一音符的满分；如果音符挨着判定线称作 Great ，获得这一音符 60% 的分；如果音符不挨着判定线则不得分。

最终按照得分进行评级：60w 以下是 D ，60w-70w 是 C ，70w-80w 是 B ，80w-88w 是 A ，88w-92w 是 S ，92w-999999 是 V ，1000000 是 Phi。
